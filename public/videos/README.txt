TELAN TECH VIDEO ASSET GUIDE
============================
To use a custom cinematic background video:
1. Place your MP4 video file in this directory:
   /public/videos/hero.mp4

2. The Hero component automatically looks for /videos/hero.mp4 by default.
   If the file is not present or while loading, an ultra-smooth cinematic data mesh canvas is seamlessly active, ensuring zero broken displays or buffering pauses.

Recommended video specifications:
- Format: MP4 (H.264 video, AAC audio or muted)
- Resolution: 1920x1080 (1080p) or 1280x720 (720p)
- Framerate: 24fps or 30fps
- File size: Under 15MB for optimal loading speeds
- Subject: Abstract digital data streams, minimalist tech architecture, clean creative motion.
